[서비스 유형]
SNS·콘텐츠 게시 자동화 도구

[연동 서비스명]
ViralPick - 개인용 SNS 상품 콘텐츠 제작 도구

[서비스 URL]
검수 담당자가 직접 접속 가능한 데모 URL 입력

[사용 목적과 노출 방식]
ViralPick은 제가 개인적으로 운영하는 Threads, Instagram, 블로그 등 SNS 채널의 상품 소개 콘텐츠 제작을 자동화하기 위해 사용하는 내부용 도구입니다.

토스쇼핑 Open API를 통해 베스트 상품, 카테고리별 인기 상품, 하루특가 상품 등 SNS에서 소개할 상품 후보를 확인하고, 게시할 상품을 선택합니다. 선택한 상품의 상품명, 판매가, 할인 정보, 리뷰 등 필요한 정보를 바탕으로 Threads 및 Instagram에 적합한 상품 소개 문구와 게시글 초안을 제작합니다.

실제로 게시할 상품에 대해서는 쉐어링크 Open API를 이용해 쉐어링크를 발급하며, 게시물에는 제휴 사실 안내 문구를 함께 표시합니다. 게시 전에는 상품 상세 정보를 다시 조회해 최신 가격과 판매 상태를 확인하고, 생성된 게시글은 제가 직접 확인·수정한 후 개인적으로 운영하는 SNS 채널에 게시합니다.

주요 사용 흐름은 다음과 같습니다.
1. 토스쇼핑 인기·특가·카테고리 상품 확인
2. SNS에서 소개할 상품 선택
3. Threads·Instagram용 게시글 초안 생성
4. 게시할 상품의 쉐어링크 발급
5. 최신 상품 정보 및 제휴 고지 확인
6. 직접 검수 후 개인 SNS 채널에 게시

ViralPick은 외부 사용자에게 상품을 검색·판매하거나 카테고리별로 둘러보게 하는 쇼핑몰 서비스가 아닙니다. 또한 토스 Open API로 받은 상품·가격 정보를 장기간 축적하여 공개 상품 카탈로그나 타 쇼핑몰과의 가격비교 서비스로 제공하지 않습니다. Open API 정보는 개인 SNS 콘텐츠를 제작하고 게시 전 최신 상태를 확인하는 데 필요한 범위에서 사용합니다.
