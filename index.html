1. 인기·특가 상품 확인
2. 소개할 상품 선택
3. Threads 글 생성
4. 이미지 문구 생성
5. 쉐어링크 발급
6. 직접 검수 후 게시

쉐어링크 · 게시 준비

게시할 상품을 최종 선택한 뒤 쉐어링크를 발급하고, 제휴 사실 안내 문구를 함께 확인합니다. 생성된 게시글은 자동 게시 전에 직접 검수·수정합니다.

제휴 고지 예시
이 게시물은 토스쇼핑 쉐어링크 활동의 일환으로 일정액의 수수료를 제공받을 수 있습니다.

서비스 운영 방식

ViralPick은 외부 사용자가 상품을 검색하거나 구매하는 쇼핑몰이 아닙니다. 토스 Open API 상품 정보는 개인 SNS 콘텐츠 제작과 게시 전 최신 정보 확인에 필요한 범위에서만 사용하며, 공개 상품 카탈로그나 타 쇼핑몰 가격비교 서비스로 제공하지 않습니다.
