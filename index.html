Open API 데이터 사용 원칙

API 상품정보는 게시할 콘텐츠를 만들고 게시 전 최신 상태를 확인하는 데 필요한 범위에서 사용합니다. 외부 사용자를 위한 상품 카탈로그나 타 쇼핑몰 가격비교 화면으로 제공하지 않습니다.
