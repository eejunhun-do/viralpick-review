서버 API 연결

연결 전
현재 GitHub Pages는 정적 시연 페이지입니다. Vercel Functions를 배포한 뒤 URL과 암호를 입력하면 서버 기능을 사용할 수 있습니다.

API 키는 이 페이지에 입력하지 마세요. OpenAI·토스 토큰은 Vercel 환경변수에만 저장하고, 연결 암호도 브라우저 저장소에 보관하지 않습니다.

토스 상품 가져오기

승인 명세 설정 대기
현재는 공식 승인 API의 조회 URL·인증 형식을 서버에 설정해야 동작합니다. 실제 상품 데이터를 축적한 공개 쇼핑몰이나 가격비교 서비스는 만들지 않습니다.

직접 사진을 올리거나 서버 연결 후 GPT Image 2로 새로운 상황 이미지를 생성하세요.

상황 이미지는 AI가 생성할 수 있지만 제품의 정확한 외형은 임의로 만들어서는 안 됩니다. 실제 상품 사진은 별도로 업로드해 3번째 상품 카드에 합성합니다. 이미지 파일은 브라우저 메모리에 남으며 새로고침 후에는 다시 업로드해야 합니다.

자동게시 · 예약게시 운영 설정

플랫폼별 게시량과 간격을 제한하고, 상품 상태가 바뀌면 자동으로 게시를 멈추도록 설정합니다.

게시 방식

검수 후 자동
① 수동 게시콘텐츠만 만들고 사용자가 직접 플랫폼에서 게시합니다.
② 검수 후 자동사용자가 승인한 콘텐츠만 지정 시간에 자동 게시합니다.
③ 완전 자동상품 선정부터 생성·검사·게시까지 조건 충족 시 자동 진행합니다.
프로토타입에서는 실제 SNS 게시를 실행하지 않습니다. Meta 계정 연결과 API 권한이 준비되면 Threads·Instagram 게시 기능을 서버에서 실행하는 구조입니다.
