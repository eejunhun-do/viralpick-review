서버 API 연결

연결 전
Vercel 프로젝트 생성은 확인됐습니다. 이제 서버의 연결 암호와 OpenAI API 키를 Vercel 환경변수에 등록한 뒤 연결을 확인하세요. 배포 보호 설정에 따라 외부 호출이 차단될 수 있습니다.

API 키는 여기에 입력하지 마세요. OpenAI·쿠팡 파트너스 키는 Vercel 환경변수에만 저장합니다. Vercel 배포 보호 기능이 모든 접속을 차단하면 GitHub Pages에서 API를 호출할 수 없습니다. 서버 보안 설정을 확인하세요.

상황 이미지는 AI가 생성할 수 있지만 제품의 정확한 외형은 임의로 만들어서는 안 됩니다. 실제 상품 사진은 별도로 업로드해 3번째 상품 카드에 합성합니다. AI 생성 사진은 이 브라우저의 IndexedDB에 상품별 최근 3세트까지 저장됩니다. 저장한 기록은 같은 브라우저에서 다시 접속할 때 복원되며, 기기가 다르면 동기화되지 않습니다.

자동게시 · 예약게시 운영 설정

플랫폼별 게시량과 간격을 제한하고, 상품 상태가 바뀌면 자동으로 게시를 멈추도록 설정합니다.

게시 방식

검수 후 자동
① 수동 게시콘텐츠만 만들고 사용자가 직접 플랫폼에서 게시합니다.
② 검수 후 자동사용자가 승인한 콘텐츠만 지정 시간에 자동 게시합니다.
③ 완전 자동상품 선정부터 생성·검사·게시까지 조건 충족 시 자동 진행합니다.
프로토타입에서는 실제 SNS 게시를 실행하지 않습니다. Meta 계정 연결과 API 권한이 준비되면 Threads·Instagram 게시 기능을 서버에서 실행하는 구조입니다.
